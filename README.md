# Greenlight

Greenlight is a JSON API for retrieving and managing information about movies.
You can think of the core functionality as being a bit like [Open Movie Database API](https://www.omdbapi.com/).

This is actually the code for the fantastic book [Let's Go Further](https://lets-go-further.alexedwards.net/) by Alex Edwards.
I am following this book to learn how to build simple but production-ready Go backend APIs.

Happy coding!
